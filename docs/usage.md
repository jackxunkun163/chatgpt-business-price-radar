# ChatGPT Business 价格雷达 · 使用说明

> Business Toolkit = **价格雷达**（查全球月付价格）+ **脚本生成器**（Team 优惠 / Codex 按量 / 账单查询）。
> 价格数据来自 `chatgpt.com` 公开匿名结账接口；所有脚本生成与敏感输入都在浏览器本地完成，不上传、不落库。

## 2. 快速上手（四步）

1. **打开页面**：部署完成后访问 `http://服务器IP:8080`，价格雷达默认加载。
2. **搜索地区**：在搜索框输入国家名、ISO 代码或币种（如 `日本`、`JP`、`JPY`）。
3. **对比价格**：按换算后价格排序（默认），切 USD/CNY 看不同口径，用含税/未含税筛选对齐口径。
4. **生成脚本**：点某地区行的「生成脚本」直接进入 Team 优惠工具（国家、货币已带入），或用顶部导航切换三个工具。

## 3. 价格雷达详解

### 概览卡片

| 卡片 | 含义 |
| :-- | :-- |
| 最低月价 | 当前快照中换算价格最低的地区（按当前显示币种） |
| 覆盖地区 | 快照包含的地区数（采集时请求 249 个 ISO 地区，未开放/无报价的不计入） |
| 显示币种 | USD（按美元中间价折算）或 CNY（USD × USD→CNY 汇率） |
| 暂旧数据 | 采集时临时失败、沿用 14 天内旧结果的地区数量 |

### 价格表每一列

| 列 | 说明 |
| :-- | :-- |
| 国家/地区 | 旗帜 emoji + 中文名 + ISO 代码 |
| 官方原币月价 | 结账接口返回的每用户月价 + 货币符号（如 `¥ 1,450`、`R$ 140`） |
| 换算价格 | 按公开汇率换算的 USD / CNY 估算值，仅作对比参考 |
| 税务口径 | **含税** / **未含税**——接口原样标注，不自行加税 |
| 状态 + 时间 | 「新鲜」= 本次采集成功；「数据暂旧」= 沿用 14 天内上次成功结果；旁边显示采集时间 |
| 操作 | 「生成脚本」带入该地区进入 Team 优惠工具；源链接可直达官方价格配置 |

### 筛选与排序

- **搜索**：国家名（中/英）、两位代码、三位币种代码，不分大小写。
- **税务口径**：全部 / 含税 / 未含税。跨地区比价建议固定同一口径。
- **数据状态**：全部 / 新鲜 / 暂旧。
- **排序**：换算价格升序（默认）/ 原币价格 / 最近更新。
- 桌面为表格；移动端自动切换为卡片，信息不缺失。

### 「本地演示快照」横幅

出现此横幅说明 `data/prices.json` 不存在（镜像构建时采集失败自动回退演示数据）。等待下一次 CI 重建镜像（每两天）后 `docker pull` 更新即可；急用可按 README「从源码构建」在有外网的环境自行采集构建。

## 4. 脚本生成器详解

顶部导航点击「脚本生成器」进入，也可从价格表某一行带入国家直接进入。三个工具都是**纯本地生成文本**：不在本站请求任何登录凭证、支付或账单接口，也不会代替你执行代码——生成的脚本需要你自己在**已登录 ChatGPT 的页面控制台**里运行。

### ① Team 优惠（使用优惠码新建/应用 Team 空间）

| 参数 | 说明 |
| :-- | :-- |
| 优惠码 | Team 优惠码（仅本地处理，不写入网址或存储） |
| 国家 / 货币 | 结账地区与币种（39 种货币；从价格表进入会自动带入） |
| 计费周期 | 月付 / 年付 |
| 席位数 | 标准席位数量（Business 通常至少 2 个） |
| 工作区名称 | 新建空间时的名称（默认 `xxx`） |
| 已有空间 UUID | 留空 = 新建空间；填写 = 将优惠应用到已有 0.52 Codex 空间 |
| Access Token | 默认「自动获取」（脚本运行时从登录 Session 取）；也可手动粘贴原始 `accessToken` 或 `/api/auth/session` 的完整 JSON（只提取 accessToken） |

左侧填参数，右侧**实时预览**生成的 JavaScript；可一键复制或下载 `team-checkout.js`。脚本运行成功后会自动打开结账页面。

### ② Codex 按量（购买 Workspace Credit）

参数：空间名称（默认 `work`）、Credit 数量（默认 `13`）、国家（自动匹配货币）、Access Token（同上）。产出 `codex-usage-checkout.js`。

### ③ 账单查询

无需业务参数，配置 Access Token 后生成 `billing-query.js`，在控制台运行可查询：账户信息、**最近 10 条发票**、支付方式、账单资料。

> ⚠️ 账单输出可能包含敏感付款资料，请勿截图/分享控制台输出。仅在有权操作的账号中使用，一切以 ChatGPT 页面实际结果为准。

## 5. 数据口径与隐私

- **来源**：`https://chatgpt.com/backend-anon/checkout_pricing_config/configs/{国家代码}`（公开匿名接口，不携带 Cookie / 设备 ID / 登录凭据）。
- **汇率**：Frankfurter 主源、open.er-api.com 补齐；`USD = 本币 ÷ USD→本币汇率`，`CNY = USD × USD→CNY`。换算值仅为估算，不含发卡行汇率与手续费。
- **展示**：仅标准 Business 月付每用户价，不含年付/非营利套餐；不自行加税。
- **刷新**：CI 每两天采集一次并重建镜像；单地区临时失败沿用最多 14 天旧值并标记「暂旧」。
- **发布保护**：首次快照须有新鲜 US、≥1 个非 USD 地区、CNY 汇率、≥20 个有效地区；后续快照行数不得低于上次的 90%，否则拒绝发布。
- **隐私**：优惠码、Token、空间信息只在浏览器内存中处理，不写入网址、localStorage 或任何服务器。

## 6. Docker 部署与更新

### 一条命令运行

```bash
docker run -d --name price-radar --restart unless-stopped \
  -p 8080:80 \
  kunkun66/chatgpt-business-price-radar:latest
```

### 1Panel 编排

容器 → 编排 → 创建编排 → 编辑内容，粘贴：

```yaml
services:
  price-radar:
    image: kunkun66/chatgpt-business-price-radar:latest
    container_name: price-radar
    restart: unless-stopped
    ports:
      - "8080:80"
```

### 更新（每两天有新价格）

```bash
docker pull kunkun66/chatgpt-business-price-radar:latest
docker compose up -d        # 编排目录内执行；1Panel 编排页点「重建」等效
```

### 架构与端口

| 项 | 值 |
| :-- | :-- |
| 支持平台 | linux/amd64、linux/arm64 |
| 容器端口 | 80（nginx 静态站） |
| 宿主机端口 | 默认映射 8080，可改 `-p 端口:80` |
| 数据卷 | 无需（纯静态，数据随镜像更新） |
| 镜像体积 | 约 50MB |

### 自定义数据（可选）

价格文件是静态的 `/usr/share/nginx/html/data/prices.json`。若想在不动镜像的情况下替换数据，可把自行采集的快照 bind mount 覆盖：

```bash
docker run -d --name price-radar -p 8080:80 \
  -v /path/to/prices.json:/usr/share/nginx/html/data/prices.json:ro \
  kunkun66/chatgpt-business-price-radar:latest
```

（采集方法：克隆仓库后 `npm install && npm run collect`，产物在 `public/data/prices.json`。）

## 7. 常见问题

**Q：价格和结账页不一致？**
表格为接口返回的每用户月价，不含企业税号、VAT/GST、反向征税、发卡行汇率和手续费的影响；以结账页实际金额为准。

**Q：为什么有些地区显示「数据暂旧」？**
该地区本次采集临时失败，系统沿用 14 天内上次成功结果并明确标记；超龄数据会被丢弃而不是显示。

**Q：换算价能当支付价吗？**
不能。USD/CNY 是公开汇率中间价估算，仅用于横向对比；实际扣款币种与金额以结账页为准。

**Q：脚本生成器安全吗？**
生成器只产出文本，不在本站请求登录凭证或执行代码。优惠码/Token 只在浏览器本地处理；但生成的脚本在你自己账号的页面上运行，请自行确认内容后再执行，并勿分享账单查询输出。

**Q：镜像里显示「本地演示快照」怎么办？**
构建时采集失败（构建机访问不了 chatgpt.com 或汇率接口）会回退演示数据。等下一次 CI 重建，或按 README 用可访问外网的环境从源码构建。

**Q：能否内网/离线部署？**
可以。镜像是自包含静态站，运行不需要出网；只是价格停留在镜像构建时刻，更新需重新拉取镜像。
